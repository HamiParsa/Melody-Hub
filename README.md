## 🎶 About MelodyHub

**MelodyHub** is a visually stunning and modern music discovery platform built with **Next.js**, **React**, and **TypeScript**.  
It delivers an immersive, elegant, and dynamic experience where users can explore genres, artists, and global music trends — all wrapped in a sleek, neon-inspired interface with smooth animations.

This project highlights front-end mastery, combining **Framer Motion**, **Tailwind CSS**, and **React Icons** to create a luxurious yet fast experience for music lovers.

---

## 🚀 Features

<ul>
  <li>🎵 <b>Dynamic Home Page</b> with motion transitions and gradient animations</li>
  <li>🎧 <b>Artists Page</b> showcasing top global artists with motion cards, glowing effects, and hover animations</li>
  <li>🎹 <b>Genres Page</b> with smooth gradient backgrounds and motion-based reveal sections</li>
  <li>📖 <b>About Page</b> featuring interactive statistics and soft motion effects for a modern aesthetic</li>
  <li>📱 <b>Responsive Design</b> for mobile, tablet, and desktop views</li>
  <li>🎬 <b>Framer Motion Animations</b> for smooth page transitions and card entrances</li>
  <li>🖼️ <b>Neon Glow & Gradient Effects</b> giving a premium visual identity</li>
  <li>🌙 <b>Glassmorphism Header & Footer</b> with hamburger menu and social icons</li>
</ul>

## 💡 Description

**MelodyHub** is not just a website — it's a visual and sensory experience.  
Users can browse artists, explore genres, and dive into the rhythm of music with animations, glows, and modern motion-based UI.

✨ **Key Highlights:**
- Clean and elegant architecture using Next.js + TypeScript  
- Interactive hover animations with 3D feel  
- Beautiful transitions and glowing UI with Framer Motion  
- Fully responsive for all screen sizes  
- Smooth hamburger menu with slide-in navigation  
- Gradient backgrounds and neon color palette for a unique aesthetic
